# mintzone

Mint timestamps and zone durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/mintzone/

## Install / run

```bash
git clone https://github.com/theworker02/mintzone.git
cd mintzone
node src/cli.js
node --test
```
